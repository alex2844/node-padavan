# padavan

[RU] | [[EN]](../../README.md)

Библиотека Node.js для управления роутерами с прошивкой **Padavan**.

Она взаимодействует с роутером через его **Веб-интерфейс (HTTP)**, предоставляя
программный доступ к функциям настройки, диагностики и управления прошивкой.

## Миграция

Обновляетесь с v1? Ознакомьтесь с [Руководством по миграции](../../docs/ru/MIGRATION.md)
для информации о критических изменениях (переход с SSH на HTTP, новый
конструктор) и удаленных функциях.

## Установка

```bash
npm install padavan
```

## Использование

```javascript
import Padavan from 'padavan';

const client = new Padavan({
    credentials: {
        host: '192.168.1.1',
        username: 'admin',
        password: 'password'
    },
    logLevel: 'error'
});

// Получить статус системы
const status = await client.getStatus();
console.log(`Uptime: ${status.uptime}`);
```

## Конфигурация

Конструктор принимает объект конфигурации со следующими свойствами:

| Свойство | Описание |
| --- | --- |
| `credentials` | Объект с данными для подключения. |
| `logLevel` | Уровень логов: `'none'`, `'error'`, `'info'`, `'debug'`. |

### Объект Credentials

| Свойство | Описание |
| --- | --- |
| `host` | IP-адрес или хостнейм роутера. |
| `username` | Имя пользователя веб-интерфейса. |
| `password` | Пароль веб-интерфейса. |
| `repo` | GitHub `owner/repo` для обновлений прошивки. |
| `branch` | Ветка GitHub (например, `main`). |
| `token` | GitHub PAT для доступа к Actions/Artifacts. |

## API

### Система и Диагностика

- **`getStatus()`**
  Возвращает загрузку CPU, RAM, время работы (uptime) и статус Wi-Fi.
- **`getLog()`**
  Получает полный системный журнал.
- **`exec(command)`**
  Выполняет системную команду через эмулятор веб-консоли (`SystemCmd`).
  *Возвращает:* Вывод команды (stdout + stderr).
- **`sendAction(action, payload?)`**
  Отправляет низкоуровневое действие на `apply.cgi`.
  *Аргументы:* `action` (строка, например `' Reboot '`), `payload` (объект с данными).
  *Возвращает:* Ответ сервера (результат команды или статус).
- **`startReboot()`**
  Перезагружает роутер через HTTP команду.

### Сеть и Клиенты

- **`getDevices()`**
  Возвращает список подключенных клиентов (из ARP таблицы и драйвера Wi-Fi).
  *Свойства:* `mac`, `ip`, `hostname`, `type` (eth, wifi, 2.4GHz, 5GHz),
  `rssi`.
- **`getHistory()`**
  Возвращает статистику трафика.
  *Структура:* `{ daily: [...], monthly: [...] }`.

### Инструменты Wi-Fi

- **`startScan(band)`**
  Выполняет сканирование эфира (Site Survey).
  *Диапазон:* `'2.4'` или `'5'`.
- **`getBestChannel(band)`**
  **Wi-Fi Доктор**: Сканирует окружение, рассчитывает уровень помех и
  рекомендует оптимальный канал для роутера.

### NVRAM и Настройки

- **`getParams(keys?, page?)`**
  Возвращает переменные NVRAM.
  *Аргументы:*
  - `keys`: Имя ключа или массив ключей. Если не указано, возвращает всё.
  - `page`: Если указано, парсит поля ввода с конкретной ASP страницы вместо
    использования `nvram show`.
- **`setParams(params, options?)`**
  Устанавливает переменные NVRAM.
  *Опции:* `action_mode` (например, `' Apply '`), `sid_list` (Service ID для
  перезапуска), `group_id`, `current_page`.

### Управление прошивкой

Требует настройки GitHub credentials (`repo`, `branch`, `token`).

- **`findFirmware(model?)`**
  Ищет артефакты прошивки в сети репозитория (включая форки).
- **`getChangelog()`**
  Сравнивает текущую версию на роутере с последним артефактом и возвращает
  список изменений.
- **`startBuild()`**
  Запускает процесс сборки прошивки (workflow) на GitHub.
- **`startUpgrade()`**
  Скачивает последний артефакт, загружает его на роутер и прошивает.
