# Интерфейс командной строки (CLI)

Пакет `padavan` включает CLI-утилиту для управления роутером прямо из
терминала. Она поддерживает мониторинг, настройку, диагностику и управление
прошивкой.

## Установка

Можно запускать через `npx` без установки:

```bash
npx padavan --help
```

Или установить глобально:

```bash
npm install -g padavan
padavan --help
```

## Настройка

Данные для подключения можно передавать через аргументы командной строки или
через переменные окружения.

### Основные аргументы

- `--host`: IP-адрес роутера (по умолчанию: `192.168.1.1`).
- `--port`: HTTP порт роутера (по умолчанию: `80`).
- `--user`: Имя пользователя (по умолчанию: `admin`).
- `--password`: Пароль администратора (по умолчанию: `admin`).
- `--json`: Вывод результата в формате JSON.
- `--verbose`: Включить подробное логирование.

### Аргументы прошивки

Используются только для команд `firmware`.

- `--repo`: GitHub репозиторий `владелец/имя` (по умолчанию:
  `alex2844/node-padavan`).
- `--branch`: Ветка GitHub.
- `--token`: Персональный токен доступа GitHub (PAT).
- `--model`: Фильтр по модели устройства (для поиска).

### Переменные окружения

Чтобы не вводить учетные данные каждый раз, вы можете экспортировать следующие
переменные в вашей оболочке:

- `PADAVAN_HOST`
- `PADAVAN_PORT`
- `PADAVAN_USER`
- `PADAVAN_PASSWORD`
- `PADAVAN_REPO`
- `PADAVAN_BRANCH`
- `PADAVAN_TOKEN`
- `PADAVAN_MODEL`

## Команды

### Система и Мониторинг

- **`padavan status`**
  Показать загрузку CPU, RAM и время работы.
- **`padavan log`**
  Вывести системный журнал.
- **`padavan traffic`**
  Показать статистику трафика (за день и месяц).
- **`padavan reboot`**
  Перезагрузить роутер.

### Сеть и Wi-Fi

- **`padavan devices`**
  Список подключенных клиентов (IP, MAC, тип подключения).
- **`padavan scan [band]`**
  Сканирование эфира Wi-Fi (Site Survey).
  *Диапазон:* `2.4` (по умолчанию) или `5`.
- **`padavan doctor [band]`**
  Анализ Wi-Fi окружения и рекомендация лучшего канала.

### Настройки (NVRAM)

- **`padavan params [keys..]`**
  Получить переменные NVRAM.
  *Пример:* `padavan params rt_ssid rt_channel`
  *Опции:* `--page <file.asp>` (парсинг полей с конкретной страницы).
- **`padavan set <pairs..>`**
  Установить переменные NVRAM.
  *Пример:* `padavan set rt_ssid=MyWifi rt_channel=auto`
  *Опции:*
  - `--action`: Режим действия (например, `Apply`, `Reboot`).
  - `--sid`: Service ID для перезапуска (например, `WLANConfig11b`).
  - `--group`: ID группы (для списков).
  - `--page`: Контекст страницы.

### Прошивка

- **`padavan firmware search`**
  Поиск артефактов прошивки в сети репозиториев.
- **`padavan firmware changelog`**
  Проверка обновлений и просмотр списка изменений.
- **`padavan firmware build`**
  Запуск процесса сборки (workflow) на GitHub.
- **`padavan firmware upgrade`**
  Скачивание последнего артефакта и прошивка роутера.
