# История

Получает статистику использования трафика.

## Выходы

1. **Стандартный выход**
   - `msg.payload` (`object`): Полный объект истории с роутера (массивы
     `daily` и `monthly`).
   - `msg.networkUsage` (`string`): Общий трафик за текущий период (Месяц
     или День) в читаемом формате (например, "15.2 GB").
   - `msg.networkUsageMB` (`number`): Общий трафик в мегабайтах (целое
     число).

## Детали

Узел автоматически отдает приоритет **Месячной** статистике.

1. Если есть история за месяц, `networkUsage` показывает итог за текущий
   месяц.
2. Если месячной истории нет (сброс или начало месяца), используются данные
   за **День**.

Этот формат данных оптимизирован для передачи в голосовые ассистенты
(например, Google Home) и дашборды.
