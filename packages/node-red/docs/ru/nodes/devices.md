# Устройства

Получает список подключенных в данный момент клиентов.

## Выходы

1. **Стандартный выход**
   - `msg.payload` (`array`): Массив объектов устройств. Каждый содержит:
     - `hostname`: Имя устройства.
     - `ip`: IP-адрес.
     - `mac`: MAC-адрес.
     - `type`: Тип подключения (`eth`, `2.4GHz`, `5GHz`).
     - `rssi`: Уровень сигнала (для Wi-Fi клиентов).
   - `msg.numConnectedDevices` (`number`): Общее количество подключенных
     устройств.
   - `msg.changes` (`object`): Сводка изменений с последнего опроса.
     - `hasChanges` (`boolean`): `true`, если были изменения.
     - `added` (`array`): Список новых устройств.
     - `removed` (`array`): Список отключившихся устройств.
     - `changed` (`array`): Список устройств с изменившимися параметрами (IP,
       имя, тип).

## Детали

Любое входящее сообщение инициирует обновление списка.

Узел использует **умное кэширование** для фильтрации "фантомных" записей
(например, когда устройство при отключении от Wi-Fi на короткое время
появляется в ARP как проводное).
