# Конфигурация

Настройка подключения к роутеру и репозиторию GitHub.

## Роутер

Параметры для доступа к веб-интерфейсу Padavan.

- **Адрес**: IP-адрес или хостнейм роутера (например, `192.168.1.1`).
- **Имя пользователя**: Логин администратора (обычно `admin`).
- **Пароль**: Пароль администратора.

## Github

Настройки для обновлений и сборки прошивки. Требуются только для узла
`Upgrade`.

- **Репозиторий**: URL или строка `владелец/имя` (например,
  `alex2844/padavan-builder`).
- **Ветка**: Ветка для сборки и проверки обновлений (например, `main`).
- **Токен**: Персональный токен доступа (PAT) с правами на Actions и
  Artifacts.
