# Обновление

Управление жизненным циклом прошивки через GitHub Actions.

## Действия (`msg.topic`)

- **Проверить обновления** (`changelog`):
  - Проверяет наличие новой версии прошивки в репозитории GitHub.
  - Выход: Объект с `from` (текущая), `to` (новая) и `messages` (список
    изменений).
- **Собрать прошивку** (`build`):
  - Запускает процесс сборки (workflow) в настроенном репозитории.
- **Прошить роутер** (`upgrade`):
  - Скачивает последний успешный артефакт сборки.
  - Загружает его на роутер.
  - Прошивает и перезагружает устройство.

## Требования

Требует наличия валидных учетных данных **Github** (Репозиторий, Ветка,
Токен) в узле конфигурации.
