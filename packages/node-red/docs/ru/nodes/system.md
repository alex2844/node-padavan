# Система

Диагностика системы и управление питанием.

## Входы

- **Действие** (`msg.topic`):
  - `status`: Получить статус системы (CPU, RAM, Uptime).
  - `log`: Получить системный журнал.
  - `reboot`: Перезагрузить роутер.
  - `scan`: Сканировать эфир Wi-Fi (Site Survey).
  - `doctor`: Анализ Wi-Fi окружения и подбор лучшего канала.
- **Диапазон** (`msg.band`):
  - Используется для `scan` и `doctor`.
  - Значения: `'2.4'` или `'5'`.

## Выходы

- `msg.payload`: Результат операции (JSON объект для статуса/доктора, массив
  для сканирования, строка для лога).

## Детали

Действие **Wi-Fi Доктор** анализирует все видимые сети, рассчитывает уровень
интерференции и предлагает оптимальный канал для вашего роутера.
