# Параметры

Чтение и изменение параметров NVRAM и настроек роутера.

## Входы

- **Действие** (`msg.topic`):
  - `list`: Получить все параметры NVRAM.
  - `get`: Получить конкретные параметры (указанные в `msg.payload`).
  - `set`: Применить настройки (из `msg.payload`).
- **Данные** (`msg.payload`):
  - Для `get`: Строка (ключ) или массив строк.
  - Для `set`: Объект `{ ключ: значение }`.
- **Опции**:
  - `msg.page`: Текущая ASP страница (помогает автоматически найти Service ID).
  - `msg.sid`: Список Service ID (требуется для перезапуска служб).
  - `msg.group`: ID группы (для работы со списками).
  - `msg.script`: Скрипт действия.
  - `msg.action`: Режим действия (например, `' Apply '`, `' Add '`,
    `' Reboot '`).

## Выходы

- `msg.payload`: Запрошенные параметры (для `get`/`list`) или примененная
  конфигурация (для `set`).

## Детали

Используйте поле **Режим действия** в редакторе (или `msg.action`) для
управления тем, как применяются параметры (простая запись в NVRAM,
применение к сервису или перезагрузка).
