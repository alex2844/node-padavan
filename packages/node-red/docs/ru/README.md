# node-red-contrib-padavan

[RU] | [[EN]](../../README.md)

Набор узлов [Node-RED](https://nodered.org/) для управления роутерами с
прошивкой **Padavan**.

Этот пакет использует библиотеку `padavan` для взаимодействия с роутером через
веб-интерфейс (HTTP). Он предоставляет инструменты для мониторинга, настройки,
диагностики и управления прошивкой.

## Возможности

- **Полный контроль**: Управление настройками (NVRAM), сервисами и питанием
  через HTTP.
- **Мониторинг**: История трафика (сутки/месяц) и статус системы
  (CPU/RAM/Uptime) в реальном времени.
- **Отслеживание устройств**: Список подключенных клиентов с умной
  фильтрацией "фантомных" записей (кэш ARP).
- **Диагностика**: Встроенный сканер Wi-Fi и **"Wi-Fi Доктор"** для анализа
  помех и подбора лучшего канала.
- **Управление прошивкой**: Проверка обновлений, запуск сборки в GitHub
  Actions и прошивка роутера прямо из Node-RED.

## Установка

Установите через палитру Node-RED (Manage Palette) или выполните команду в
вашей директории Node-RED:

```bash
npm install node-red-contrib-padavan
```

## Узлы

### ⚙️ Конфигурация (`padavan-config`)

Настраивает подключение к роутеру (IP, Логин, Пароль) и опционально к
GitHub (для обновлений прошивки). Поддерживает безопасное хранение учетных
данных.

### 🖥️ Система (`padavan-system`)

Выполняет системные операции и диагностику.

- **Получить состояние**: Загрузка CPU, использование RAM, время работы.
- **Получить лог**: Загрузка системного журнала.
- **Перезагрузить**: Перезагрузка роутера.
- **Сканировать Wi-Fi**: Поиск сетей в эфире (2.4GHz / 5GHz).
- **Wi-Fi Доктор**: Анализ окружения и рекомендация оптимального канала.

### 📱 Устройства (`padavan-devices`)

Получает список подключенных клиентов.

- Возвращает IP, MAC, Имя хоста, Тип подключения и RSSI.
- Вычисляет изменения (добавленные/удаленные/измененные устройства) с
  момента последнего опроса.
- Фильтрует временные "фантомы" Ethernet, возникающие при отключении
  устройств от Wi-Fi.

### 📊 История (`padavan-history`)

Получает статистику использования трафика.

- Отдает приоритет статистике за **Месяц** (для расчетного периода).
- Использует статистику за **День**, если данные за месяц отсутствуют.
- Предоставляет готовое поле `networkUsageMB` для легкой интеграции с
  голосовыми ассистентами (например, Google Home).

### 🔧 Параметры (`padavan-params`)

Низкоуровневый доступ к настройкам роутера (NVRAM).

- **Список**: Получить все переменные NVRAM.
- **Получить**: Прочитать конкретные переменные.
- **Установить**: Изменить переменные с поддержкой `sid_list` (перезапуск
  сервисов) и различных режимов применения.

### ☁️ Обновление (`padavan-upgrade`)

Управление жизненным циклом прошивки через GitHub Actions.

- **Проверить обновления**: Сравнение текущей версии с последним артефактом.
- **Собрать**: Запуск процесса сборки (workflow) в вашем репозитории.
- **Прошить**: Скачивание артефакта и обновление роутера.
